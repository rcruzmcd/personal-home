# Rickie Cruz Personal Website — Project Overview

## Project Goal

Create a polished personal digital presence that demonstrates expertise in software engineering, UI development, systems architecture, and technology operations while providing a home for personal projects and building a pipeline for consulting/freelance leads.

## Strategic Positioning

**Brand Statement:**
> Software engineer who builds useful digital products and helps organizations make better technology decisions.

**Avoid positioning as:**
- "Web developer"
- "React developer"
- "Freelancer"
- "UI designer"

**Demonstrate capability across:**
Product → UI → Engineering → Architecture → Infrastructure → Operations

## Primary Audiences

1. Potential employers/recruiters
2. Potential consulting/freelance clients
3. Professional network
4. Friends/community
5. People interested in the projects themselves

## Primary Conversion

**Start a conversation** — not "Download Resume"

The website itself should be evidence of quality work. Landing on it should immediately signal: "This person knows what they're doing."

## Key Principles

1. **Demonstrate, don't describe** — The site itself proves your quality
2. **Case studies > resume** — Show how you think, not just what you built
3. **Thoughtful UI, not flashy** — fast + intentional + usable, not "look how many animations"
4. **Build for consulting from day one** — Architecture allows adding consulting features later without redesign
5. **Nonprofit-friendly positioning** — You have credibility here; lean into it
6. **Simple tech stack** — Next.js + Vercel, focus on content not infrastructure

- Responsive across devices
- Fast Core Web Vitals
- Accessible to keyboard and screen reader users
- Clear, compelling case studies
- Professional presence that generates leads
