# rickiecruz.com

The personal site for Rickie Cruz — homepage, About, Work and Projects case studies
(MDX), Consulting, Resume, and a Contact form backed by Resend. Deployed on Vercel.

Part of the [`personal-home` monorepo](../README.md); requirements and product
decisions live in [`../docs/`](../docs).

## Stack

- **Next.js 16** (App Router) with **React 19** and the **React Compiler** enabled
  (`reactCompiler: true` in `next.config.ts`) — avoid hand-written `useMemo`/`useCallback`.
- **TypeScript** (strict), path alias `@/*` → `./src/*`.
- **Tailwind CSS v4**, CSS-first — theme tokens live in `src/app/globals.css`, not a
  `tailwind.config.js`.
- **shadcn/ui** primitives in `src/components/ui`.
- **MDX** case studies in `content/`, validated by the Zod schema in `src/lib/content`.
- **Vitest** for tests, **Vercel Analytics** for events.

## Getting started

This project uses **bun** (`packageManager: bun@1.3.14`). Don't use npm, yarn, or pnpm.

```bash
bun install
bun dev            # dev server at http://localhost:3000
bun run build      # production build
bun start          # serve the production build
bun run lint       # eslint
bun test           # vitest run
bun run test:watch
bun run test:coverage
```

## Environment

| Variable | Required | Purpose |
| --- | --- | --- |
| `RESEND_API_KEY` | Production | Sends contact-form submissions. Without it, submissions are logged to the server console instead of emailed, and the visitor still gets a success response. |

## Layout

```
content/            MDX case studies (work/, projects/) with frontmatter
src/app/            App Router routes, sitemap.ts, robots.ts, api/contact
src/components/     ui/ (shadcn primitives), site/, content/, project/, case-study/
src/lib/            content loading + schema, seo, analytics, email, validation
```

## Conventions

- Read `docs/UX_PATTERNS.md` before laying out a new page — `PageHeader`, `Breadcrumb`,
  and `Stat` carry the shared rules; don't hand-roll a page's title block.
- Read `docs/STYLE_SYSTEM.md` before picking colors or spacing.
- `CLAUDE.md` and `AGENTS.md` in this directory are regenerated by `next dev`. Don't
  hand-edit them.
