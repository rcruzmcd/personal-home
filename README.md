# personal-home

A monorepo housing personal projects including a portfolio of work, personal finance tools, and personal site.

## Project Structure

### `/docs`
Documentation, requirements, and project information including:
- Project overview and vision
- Tech stack and domain documentation
- Website requirements
- Personal finance requirements
- Case studies and timeline

### `/personal-home`
A Next.js project serving as the main portfolio and personal website. This will be built out as a comprehensive showcase of work and skills.

## Projects

- **Portfolio Site**: Next.js application for showcasing work and projects
- **Personal Finance**: Finance project (to be integrated or housed in this repository)
- **Personal Site**: Central hub for professional presence

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS (PostCSS)
